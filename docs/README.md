I documenti correnti sono qui. `files/` conserva gli originali ricevuti e non guida nuove implementazioni. Root `AGENTS.md` contiene le regole di lavoro; SPEC descrive il prodotto atteso, PROGRESS distingue ciò che è già verificato.
